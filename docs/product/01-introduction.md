# Introduction

## What is Flexible Request Management?

Flexible Request Management is an enterprise application for managing approval workflows. It allows organizations to:

- ✅ Create customizable request forms
- ✅ Define multi-step approval workflows
- ✅ Assign work to individuals or teams
- ✅ Track request status in real-time
- ✅ Maintain complete audit trails

---

## Key Concepts

### Requests
A **Request** is a formal submission that requires approval. Examples:
- New employee onboarding
- Budget approval
- Access requests
- Plant operations

### Steps
Each request contains **Steps** - units of work that need to be completed. Steps can be:
- **Data Collection** - Gathering information from assigned owners
- **Approval** - Review and approve/reject by designated approvers

### Roles

| Role | Description |
|------|-------------|
| **Requester** | Creates and manages requests |
| **Coordinator** | Oversees the workflow progress |
| **Step Owner** | Completes assigned data collection |
| **Approver** | Reviews and approves/rejects steps |

---

## How It Works

```
1. Requester creates a request
       ↓
2. Steps are assigned to owners
       ↓
3. Step owners complete their work
       ↓
4. Approvers review and approve/reject
       ↓
5. Request is completed or rejected
```
