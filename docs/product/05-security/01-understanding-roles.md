# Understanding Roles

> **Last Updated:** 2026-01-17

Learn about the different roles in the system and what each role can do.

---

## System Roles

These roles are assigned by your IT administrator.

| Role | Description |
|------|-------------|
| **Administrator** | Full system access, configure request types |
| **Requester** | Create and submit requests |
| **Approver** | Review and approve/reject requests |
| **Viewer** | Read-only access to approved requests |

---

## Workflow Roles

These are dynamic roles based on your relationship to a request.

| Role | When You Have It |
|------|------------------|
| **Coordinator** | You're assigned to manage the request workflow |
| **Step Owner** | You're assigned to complete a specific step |
| **Step Approver** | You're designated as approver for a step |

---

## What Each Role Can Do

### Administrator
- Configure request types in Request Type Studio
- Manage groups and users
- View all requests (for auditing)
- Override workflow actions

### Requester
- Create new requests
- View own requests
- Edit draft requests
- Cancel own requests

### Approver
- View requests in Inbox
- Approve/Reject assigned steps
- Claim group approvals
- Add comments

### Viewer
- View completed requests
- View request details
- Cannot make changes

---

## Checking Your Role

Your role appears next to your name in the header. Contact your administrator to request role changes.
