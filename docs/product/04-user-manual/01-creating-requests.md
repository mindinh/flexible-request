# Creating Requests

> **Last Updated:** 2026-01-17

Learn how to create and submit requests in the system.

---

## Quick Steps

1. Click **"New Request"** from the My Requests page
2. Select a **Request Type** (e.g., "New Plant Request")
3. Fill in the required form fields
4. Click **"Submit"** to send for approval

---

## Understanding Request Types

Each request type has different:
- **Form fields** to fill in
- **Workflow steps** to complete
- **Approvers** who need to review

Your administrator configures these in the Request Type Studio.

---

## Form Fields

Depending on the request type, you may see:

| Field Type | Description |
|------------|-------------|
| Text | Short text input |
| Number | Numeric values |
| Date | Date picker |
| Dropdown | Select from options |
| Attachment | Upload files |

---

## Saving vs Submitting

| Action | What Happens |
|--------|--------------|
| **Save Draft** | Request is saved but not submitted |
| **Submit** | Request is sent for approval |

You can edit draft requests. Once submitted, you cannot edit (unless sent back).

---

## After Submission

Once submitted, your request:
1. Appears in your **My Requests** list
2. Status changes to **SUBMITTED** or **IN_PROGRESS**
3. Assigned approvers receive notification in their Inbox
