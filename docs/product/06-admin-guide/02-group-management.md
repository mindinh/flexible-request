# Group Management

> **Last Updated:** 2026-01-17

Learn how to create and manage groups for approval assignments.

---

## What are Groups?

Groups allow you to assign approvals to a team rather than an individual. Any group member can claim and approve the request.

---

## Accessing Group Management

1. Navigate to **Organization** from the sidebar
2. Select the **Groups** tab
3. Here you can view, create, and manage groups

---

## Creating a Group

1. Click **"Create Group"**
2. Enter a group name (e.g., "Finance Approvers")
3. Add a description (optional)
4. Click **"Save"**

---

## Adding Members

1. Open a group
2. Click **"Add Member"**
3. Search for users by name or email
4. Select users to add
5. Click **"Save"**

---

## Removing Members

1. Open a group
2. Find the member to remove
3. Click the remove (X) button next to their name
4. Confirm removal

---

## Using Groups in Workflows

After creating a group, you can use it in Request Type Studio:

1. Open a Request Type
2. Add an approval rule
3. Select "Group" as the approver type
4. Choose your group

---

## Best Practices

- Keep groups small (3-5 members) for faster approvals
- Use descriptive names (e.g., "HR Department", "Finance Team")
- Review group membership quarterly
